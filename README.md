# maimai-op
Data fetcher/organizer for maimaiDX

Current features:
- Fetch play records from [maishift](https://github.com/shiftpsh/shiftpsh.com-maimai) (very slow)
- Fetch play records from maimaidx-eng.com using your CLAL value (recommended)
- Calculate Overpower per version and compare it with the theoretical Max Overpower
- Display of Possession Plates per version
- Different data storing per user
- Plot your OP change in a graph
- GUI (ish)

Roadmap:
- Independance from maishift
- Discord bot integration
